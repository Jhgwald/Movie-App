# Assets Folder

This folder should contain the following image files for the Expo app:

## Required Files:

- **icon.png** (1024x1024) - App icon
- **splash.png** (1242x2436) - Splash screen image
- **adaptive-icon.png** (1024x1024) - Android adaptive icon
- **favicon.png** (48x48) - Web favicon

## Generating Assets:

You can generate these assets using:
- [Expo Asset Generator](https://www.npmjs.com/package/expo-asset-generator)
- Or design tools like Figma, Sketch, or Photoshop

## Placeholder Images:

For development, Expo will use default placeholders if these files are missing.
The app will still run without these assets during development in Expo Go.
