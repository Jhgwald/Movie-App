# Legacy Web Version

This folder contains the original HTML/React web prototype of Movie Match.

## Files

- **index.html** - Original web app with full features (single-page app)
- **preview.html** - iPhone preview frame for testing
- **README-web.md** - Original web version documentation

## Purpose

These files are kept for reference but are **not part of the active Expo mobile app**.

The active mobile development uses the Expo React Native structure in the main project directory.

## Running the Web Version

To view the web version locally:
1. Open `index.html` in a web browser
2. Or use `preview.html` to see it in an iPhone frame

## Migration

The web version has been migrated to a native Expo mobile app with:
- Native mobile components
- Expo Router for navigation
- Better performance on iOS and Android
- Access to native device features

For active development, see the main project README.md.
